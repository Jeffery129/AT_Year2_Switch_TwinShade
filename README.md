---

| 作品情報 | HALゲーム学科・三校合同コンテスト作品（二年後期） |
|:---:|---|
| ジャンル | 2D・シューティング・スクロールアクション |
| 言語 | C++ |
| ツール | Visual Studio 2022｜Aseprite｜GIMP｜Excel |
> Excelでマップデータを作成し、CSV形式で出力したデータをゲーム内で読み込む

## 🎮 操作方法

| 操作項目 | ボタン |
|---|---|
| 移動 | 左スティック **／** 十字ボタン・左右 |
| ジャンプ | Bボタン |
| ダッシュ | Yボタン |
| 色を切り替える | Lボタン **／** Rボタン |
| 照準 | ZLボタン長押し |
| 射撃・チャージ | 照準中にZRボタン長押し、離して発射 |
